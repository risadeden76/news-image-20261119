A Node 22, standard-library-only program that draws a 1024x1024 infographic summing up the world news of Thursday 19 November 2026 — the Gaza ground raid, the Crimean Bridge attack, Anthropic's record IPO, the Trump–Xi–Putin meeting in China, the UN court's Rohingya verdict and Voyager 1 reaching a light-day — and writes it to `/output/entry.png`. All news content is baked into the program; it runs with no network and writes the same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
